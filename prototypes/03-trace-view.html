Service layer — billing-api

What happens: the invoice is validated for completeness, tax is recomputed via computeTax(), a sequential invoice number is assigned under an advisory lock, and status flips draft → open in a transaction.

async finalizeInvoice(id) {
  const inv = await this.mustBeComplete(id) // ⛨ ≥1 line, tax id
  inv.totals = await tax.computeTax(inv)
  inv.number = await this.nextNumber() // ⛨ advisory lock
  await tx([updateInvoice, writeLedger, emit('invoice.finalized')])
}

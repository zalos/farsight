# Third-party dependencies

This package uses `ajv` 8.20.0 (MIT, https://github.com/ajv-validator/ajv) for JSON Schema validation.
It is an ordinary dependency, retaining its own license and dependency notices; it is not vendored here.
The build-time schema generator is `ts-json-schema-generator` 2.9.0 (MIT); it is not a runtime dependency.
